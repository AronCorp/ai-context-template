# Hand off: continue in a fresh chat

Goal: they can carry on in a new chat with nothing lost. Nothing carries over on its own except what is in the files. A new chat can't see this one, its attachments, or anything you wrote here that wasn't saved. So: file everything durable, put every file the next chat will need somewhere it can reach, then hand it exact pointers. This chat stays open; closing it for good is "wrap up" (wrap.md).

1. Read the files fresh. Before writing anything, fetch the current version of each file you're about to change: through the connector, in the browser, or by asking them to paste it. The copy you read at the start of the chat is stale by now (guide, section 7). If the current file has lines you don't recognize, another chat wrote them: keep them.

2. Sweep the conversation for anything durable that isn't in the files yet. Decisions and changes, dated, go to log.md. A new person, or news about one, goes to people.md. A change in an area, a decision or a constraint, goes to areas.md. Tasks, things they're waiting on, and parked ideas go to now.md. How they want to be talked to, or a fact about them, goes to profile.md. File each one the "save it" way: whole file, built on the current version, only the lines this conversation changed, and say what changed. One file at a time. Anything half-done gets a one-line status in now.md: where it stands, and the exact next step.

3. Attachments and things made here. Anything uploaded to this chat, and anything you wrote in it that's worth keeping (a letter, a list, a plan), lives only in this chat. Small text goes into inbox/ as one file named by date, or into the lake if they have one (guide, section 9). Photos, PDFs and the like get saved by them to their phone or their Drive, and a file just says where. List each one and where it went. Don't say it's saved until they've seen it there.

4. Don't save the transcript. This chat stays open, so its words aren't at risk yet, and a copy taken now would go stale the moment the chat continues. The transcript is wrap-up's job.

5. Write the continuation note, under 150 words, in a grey box they can copy. Pointers, not content: the files carry the facts, the note carries the thread.

   Continuing from (date).
   Read first: (the files this chat changed).
   Files: (anything put in inbox/, or "none").
   What we were doing: (two or three sentences).
   Done: (what's finished). Next: (the single next step).
   Open questions: (list, or "none").

6. Confirm in one line: what was saved and where, that they've seen it on GitHub, and that this chat is still open and not archived. Then tell them: new chat in the Project, paste the note.

Never say something is saved unless the save worked and they've looked.
