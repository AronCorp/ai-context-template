# Skills

The step-by-step procedures behind two of the four phrases. When they say "hand off" or "wrap up", read the matching file and follow it in order. "save it" and "reset the week" are short enough to live in the guide (section 8).

- handoff.md: continue in a fresh chat without losing anything. This chat stays open.
- wrap.md: close this chat for good with nothing lost, and say when it's safe to delete.

For the person: you don't need to read these. They exist so the assistant does the same careful thing every time, and so the rules travel with your files.
